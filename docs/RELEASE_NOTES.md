# firstcut — 版本说明

用 Rust 编写的本地照片初筛工具：扫描索尼相机 JPG+ARW 目录，进行五维评分和连拍整理，并输出 CSV 报告与 XMP 星级侧车。照片在本地处理，不会上传。

## v1.4.2 — 安全加固与文档整理

- **文档归类**：现行架构设计统一维护于 [`docs/DESIGN.md`](DESIGN.md)，历史评审、旧里程碑与已停止的 darktable 研究归档至 [`docs/history/`](history/README.md)，根目录 README 精简并重构导航。
- **能力边界明确**：明确人工星级已统一、人工连拍保留覆盖仍仅在 review 生效的边界，以及真实选片、Lightroom 导入和 HDR/macOS 的未验收范围。
- **复核访问**：照片、评分及写操作需要登录；所有写接口统一校验请求来源。原图按当前照片清单流式读取，缩略图缓存有容量上限。
- **本地状态**：引入基于句柄的安全目录访问，拒绝符号链接、重解析点和异常数据库旁路日志；正常关闭的旧评分及人工决定仍可读取。场景反馈达到上限后提示手动归档。
- **导出与推理**：联系表转义元数据并限制脚本；CSV 默认保护可能被表格解释为公式的文本（程序读取可用 `--raw-csv`）。推理前核对模型 SHA-256 哈希，既有官方模型可继续使用。
- **依赖与发布**：更新 SQLite 和 Debian `zlib1g` 等依赖。Windows 发行程序通过依赖审计和合成照片复核测试，AMD64 和 ARM64 镜像通过 Trivy 归档静态扫描后发布。

升级后，Windows 启动器仍会直接打开复核页。使用 `--no-browser` 时请打开终端给出的完整链接。使用 Docker Compose 时，在 `.env` 配置 `FIRSTCUT_ACCESS_TOKEN`，然后在登录页输入该凭据。正常关闭的评分库和人工决定可继续读取。

## v1.4.1 — 安全维护与依赖升级

- **人工评分存储防护**：规范化照片根目录和 `.firstcut/`，验证状态目录仍位于所选根目录内；拒绝符号链接形式的状态目录和 `decisions.sqlite`，避免写入被重定向。普通目录的存储路径与数据库格式不变。
- **兼容性维护**：更新 clap、kamadak-exif、roxmltree、toml、toml_edit 与 GitHub Actions 缓存组件。有效配置、评分参数、已有评分缓存和 XMP 格式无需迁移。
- **验证**：组合升级通过本地全量回归（72 单元、7 集成），覆盖全部场景预设、配置注释保留和 XMP 外部字段保护；升级前后扫描同一组本地样本，31 条 CSV 记录逐字节一致。

## v1.4.0 — Linux 双架构容器

- **容器发行**：GitHub Container Registry 提供 Linux amd64 与 ARM64 镜像及自动选择架构的版本标签，支持 Apple Silicon 用户通过 Docker Desktop 运行本地复核界面。
- **运行兼容性**：容器使用与 ONNX Runtime 预编译库兼容的 Debian trixie 环境；两种架构分别在原生 runner 上构建，并以非 root 用户验证复核页面返回 HTTP 200。
- **Windows 交付**：继续提供 UI 启动器、CLI、联系表和调参程序，以及 SHA-256 校验文件。原生 macOS 二进制尚未纳入发行范围。

## v1.3.0 — 复核体验与运行一致性

- **统一 UI 与 CLI**：同一照片根目录共用 `.firstcut/cache.sqlite`、`.firstcut/config.toml`、RAW 关联偏好和 `Processed/` 跳过规则，避免因启动方式和当前工作目录不同而把已评分照片显示成未评分。
- **收纳本地状态**：默认评分报告、扫描报告、调参 CSV、联系表、缩略图、人工决定、场景反馈、界面设置和有界任务日志集中写入照片根目录 `.firstcut/`。XMP 侧车继续放在照片旁，供 Lightroom 识别。
- **复核界面**：灯箱显示缩放百分比和带单位的 EXIF 快门/焦距；直方图可拖动并按 W/R/G/B 通道切换，JPEG 网格抽样比例可在设置中调整，默认 10%。
- **运行记录**：评分任务日志显示本地时间并保存到 `.firstcut/review.log`，单文件限制 256 KiB，轮转时保留最近约 128 KiB。
- **兼容范围**：当前直方图和分析基于 SDR JPEG 解码结果；尚不支持 HDR 增益图、PQ 或 HLG。
- **验证**：UI 启动器与 CLI review 对同一照片根目录的 API 快照逐张匹配（272 张，其中 268 张已有评分）；`cargo test --locked --all-targets` 通过（72 单元、7 集成）。

## v1.2.0 — 本地复核界面里程碑

本版本把照片评分、人工复核和 Lightroom 元数据交接连成可用工作流，并修复了前端交互及评分数据来源问题。

- **可用的照片复核界面**：缩略图筛选、组/连拍快捷菜单、排序、原图预览和连拍并排对比；支持手动星级与保留决定。
- **解释评分结果**：预览中展示各评分维度、权重和分数贡献，并展示可用的场景提示；可记录场景纠正反馈，供后续分析。
- **配置更易理解**：评分参数有说明、建议范围、滑块和数值输入。
- **统一人工星级**：决定保存在照片根目录 `.firstcut/decisions.sqlite`，重新评分后仍保留；CLI、复核界面、CSV 与 XMP 使用相同的最终星级规则。
- **恢复分析可靠性**：缓存区分 AI 与纯像素模式并纳入模型文件指纹；CSV 标出分析模式和星级来源；XMP 字段合并时保留其他软件数据，解析失败时保护原文件。
- **修复细节问题**：包括复核页面脚本、时间排序、灰度 JPEG 越界、异常配置校验及 sports 预设清晰度参数方向。
- **连拍人工决定**：复核界面可快速筛选连拍组并手动覆盖保留建议；覆盖记录保存在照片根目录 `.firstcut/`。

场景提示目前仅能可靠标记人像候选，尚未提供通用场景分类或自动切换评分权重。批量 RAW 开发路线已停止，照片后期交由 Lightroom。

## v1.1 — AI 通道修复与权重修正

- 修复 SCRFD、CLIPIQA、YOLOv8-pose 预处理中 RGB 交错/平面布局混淆；当时与 v1.0 的逐像素实现逐张比对一致。
- 默认权重修正为清晰度 0.30、曝光 0.25、噪点/构图/美学各 0.15，合计 1.0。
- 增加端到端测试；私人测试集缺失时跳过相关旧用例，不要求分发样片。
