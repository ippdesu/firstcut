# Security Policy / 安全政策

## Supported versions / 支持版本

Security fixes are made for the latest stable release and the current `main` branch. Older releases may not receive security updates. Users should upgrade to the latest release when a fix is available.

安全修复面向最新稳定版和当前 `main` 分支。旧版本不保证获得安全更新；修复发布后请升级到最新版本。

## Reporting a vulnerability / 漏洞报告

Please use [GitHub's private vulnerability reporting](https://github.com/ippdesu/firstcut/security/advisories/new) to report suspected vulnerabilities. Do not open a public issue or discussion for an unpatched vulnerability. Include the affected version or commit, steps to reproduce, and potential impact. Avoid attaching real credentials or personal data.

请通过 [GitHub 私密漏洞报告](https://github.com/ippdesu/firstcut/security/advisories/new) 提交疑似漏洞。尚未修复的漏洞请勿发到公开 Issue 或讨论区。请提供受影响版本或提交、复现步骤和可能影响，并避免附上真实凭据或个人数据。

The maintainer aims to acknowledge reports within seven days and will coordinate disclosure and remediation with the reporter. Response and fix timelines depend on severity and reproducibility.

维护者会尽量在七天内确认收到报告，并与报告者协调披露和修复。响应与修复时间会根据严重程度和复现情况安排。
